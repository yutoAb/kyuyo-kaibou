# 給与解剖 (Kyuyo Kaibou)

あなたの給料はどこへ消えるのか — 年収から手取り・所得税・住民税・社会保険料への分解を
1枚のサンキー図で可視化するツール。**会社が負担している「見えない社会保険料」**まで含めた
本当の人件費が見えます。

- すべてブラウザ内で計算(入力値は送信されません)
- 2025年度(令和7年度)の税制・保険料率に基づく概算
- 計算の前提と出典は [assumptions.html](assumptions.html) にすべて公開

## 開発

静的サイトです。ローカル確認:

```bash
python3 -m http.server 8900
# http://localhost:8900 を開く
```

## 免責

一般的な制度の可視化を目的とした教育用シミュレーションであり、個別の税務相談に代わるものではありません。
