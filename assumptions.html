計算の前提と根拠

給与解剖の計算はすべてこのページの前提に基づく概算です。透明性のため、使用している率・控除・簡略化している点をすべて公開します。誤りの指摘はお問い合わせからお願いします。

本ツールは一般的な制度の仕組みを可視化する教育目的のシミュレーションであり、個別の税務相談・税務申告の助言に代わるものではありません。個別の事情に基づく判断は税理士等の専門家にご相談ください。

  • 標準報酬月額の上限: 健康保険 139万円 / 厚生年金 65万円(上限超過分には保険料がかかりません)
  • 標準報酬月額の等級表は使わず、月給の実額で近似しています(誤差は概ね月数百円〜千円程度)
  • 賞与は考慮せず、年収を12等分した月給として扱います(賞与には別途の上限があるため、賞与比率が高いと実際より保険料が多めに出ます)

所得税(2025年分・令和7年分以降の改正後)

  • 給与所得控除: 最低65万円(年収190万円以下) / 190万超〜360万: 収入×30%+8万 / 〜660万: ×20%+44万 / 〜850万: ×10%+110万 / 850万超: 195万円
  • 基礎控除(令和7・8年分の上乗せ特例込み): 合計所得132万円以下 95万円 / 〜336万円 88万円 / 〜489万円 68万円 / 〜655万円 63万円 / 〜2,350万円 58万円
  • 所得控除は社会保険料控除と基礎控除のみ(配偶者控除・扶養控除・生命保険料控除・iDeCo等は未考慮)
  • 課税所得に超過累進税率(5〜45%)を適用し、復興特別所得税(2.1%)を上乗せ
  • 定額減税などの時限措置は反映していません

住民税

  • 所得割10%(市町村民税+道府県民税)、基礎控除43万円
  • 調整控除2,500円を一律控除、均等割は森林環境税を含め5,000円
  • 本来は前年所得に対して翌年度課税ですが、当年の所得に対する額として表示しています
  • 非課税限度額の判定は簡略化しています(課税所得が0なら0円)
